# githubEdu

This repository is for learning Git and GitHub for new users.

## Getting Started with Git

### Basic Git Commands

```bash
# Configure your Git username and email
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

# Clone a repository
git clone <repository-url>

# Check the status of your files
git status

# Add files to staging area
git add <filename>
git add .  # Add all files

# Commit your changes
git commit -m "Your commit message"

# Push changes to remote repository
git push origin <branch-name>

# Pull latest changes from remote
git pull origin <branch-name>
```

## Getting Started with GitHub

1. **Fork** - Create your own copy of a repository
2. **Clone** - Download the repository to your local machine
3. **Branch** - Create a new branch for your changes
4. **Commit** - Save your changes with a descriptive message
5. **Push** - Upload your changes to GitHub
6. **Pull Request** - Request to merge your changes into the main repository
